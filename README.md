# Lord Ganesha Line Art Animation 🌸🚩

An aesthetic Python project for Ganesh Chaturthi that traces and animates divine line art of Lord Ganesha using OpenCV and Turtle Graphics.

---

## ✨ Features

- Automatically extracts contours and vector outlines from an image.
- Accurately handles inner cutouts and details.
- Animates Lord Ganesha in warm saffron/orange strokes on a dark background.

---

## 🛠️ Requirements

- Python 3.x
- opencv-python
- numpy

---

## 🚀 How to Run

1. Open your terminal in the project directory.

2. Install dependencies:
```
pip install opencv-python numpy
```


3. Make sure your image file is named bappa.jpg and kept in the project folder.

4. Run the script:
```
python bappa.py

```
